# Jenga Teacher

Кабинет преподавателя: расписание, посещаемость, профиль и отчёт о смене.
Часть монорепозитория Jenga; общие инструкции — в корневом README.

- `npm ci` — зависимости.
- `npm run dev -- --port 5174 --strictPort` — разработка.
- `npm test` — сборка и проверки артефакта.
- `PORT=3101 node dist/standalone/server.js` — Node standalone после сборки.

Демо-вход: marina / jenga2026. Настоящей авторизации и серверного сохранения пока нет.

Шрифты Open Sans размещены в public/fonts; нет зависимости от абсолютных путей
прежней среды сборки. Иконка Jenga используется в интерфейсе и manifest.
Старые неиспользуемые Cloudflare D1 примеры сохранены как код исходного проекта;
это не БД Jenga. Не применяйте их вместо будущей общей схемы.
